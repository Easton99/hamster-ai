Plugins / Default Plugins

Default Plugins

These plugins are enabled out of the box and require no extra dependencies.

Session Awareness

On by default No extra dependencies

Detects what kind of session you're having — coding, gaming, browsing, or idle — based on the active window and process. Uses this to reduce interruptions during focused work and provide smarter context to the LLM.

Session types detected

Session typeExample signals
CodingVS Code, terminal, SSMS active
GamingFullscreen game process detected
BrowsingBrowser in foreground
MediaBrowser with video title, media player
IdleNo input detected for extended period

Session data is stored as broad summaries only — no window titles from Work or Private Mode are ever saved.

Insights

On by default No extra dependencies

Generates brief activity summaries at the end of the day and the end of the week, based on session data.

Example end-of-day summary

Today looked like:
- coding: 2h 10m
- gaming: 1h 40m
- browsing: 45m

Quietly productive. Not bad.

Example weekly insight

This week:
- more coding than usual
- gaming mostly late evening
- several long PC sessions

Summaries appear once per day and once per week. No scoring, no judgement. Summaries never include Work Mode or Private Mode data.

Scheduled Reminders

On by default No extra dependencies

Handles time-based reminders set with natural language in chat.

Example usage

/remind me at 6pm to check the build
/remind me in 30 minutes to take a break
/remind me tomorrow at 9am about the standup

Settings

SettingDefaultDescription
Queue during protected modesOnReminders are held and delivered when the mode ends
Speak reminders aloudOffRequires the Voice Output plugin to be active
