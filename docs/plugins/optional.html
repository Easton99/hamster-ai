Plugins / Optional Plugins

Optional Plugins

Disabled by default. Enable them from the tray → Plugins. Some require extra packages.

Process Awareness

Off by default No extra dependencies

Gives Hamster AI visibility into what's running on your PC — running processes, apps using the internet, and programs set to start with Windows.

Example questions it enables

  • "What's running right now?"
  • "Which apps are using the internet?"
  • "What starts when Windows boots?"

Settings

SettingDefault
Show remote addressesOff
Include in LLM contextOff

Audio Awareness

Off by default Requires: pip install pycaw

Detects whether system audio is currently playing. Hamster AI uses this to avoid interrupting you during calls, music, or video playback.

What it does

  • Suppresses greetings and notifications while audio is active
  • Does not record, capture, or process audio content
  • No audio is ever saved to disk

Voice Output

Off by default Requires: pip install pyttsx3

Speaks Hamster AI's replies aloud using Windows SAPI (local text-to-speech). All speech is generated on-device — no cloud TTS.

Commands

/voiceToggle voice output on or off
/voice-testTest that speech is working

Settings

SettingDefault
Voice enabledOff
Speak greetingsOff
Speak chat repliesOff
Voice speedMedium
Voice volume100%

Voice output is automatically suppressed during Work Mode, Private Mode, Focus Mode, and Game Safe Mode. It also respects Audio Awareness — it won't speak over active system audio if that plugin is enabled.

Off by default Requires: pip install GPUtil pywin32 wmi
