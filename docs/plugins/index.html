Plugins

Optional features that load at startup. Enable only what you need.

How the Plugin System Works

Plugins live in the plugins/ folder, each in their own sub-folder. They are discovered automatically on startup. Plugins can:

  • Subscribe to app events (window changed, session started, day ended, etc.)
  • Register new slash commands
  • Add context to the LLM prompt
  • Store data in the local database
  • Show desktop notifications

Enabling and Disabling

Right-click the tray icon → Plugins. Each plugin can be toggled on or off without restarting the app.

Plugin Safety

  • A plugin crash cannot bring down the app — each plugin runs in its own isolated context
  • Plugins always respect Work Mode, Private Mode, Focus Mode, and Game Safe Mode
  • All data stored by plugins can be deleted by core Forget Mode commands
  • Plugins can only store data through approved storage APIs — no direct database access
✅

Default Plugins

Enabled out of the box. No extra dependencies required.

⚙️

Optional Plugins

Disabled by default. Some require extra pip packages to install.

Writing Your Own Plugin

Create a folder in plugins/ with a plugin.py and config.json:

plugins/
  my_plugin/
    plugin.py
    config.json

plugin.py structure

from app.plugins.plugin_base import PluginBase

class Plugin(PluginBase):
    name = "my_plugin"
    description = "Does something useful."
    enabled_by_default = False

    def on_start(self, app): ...
    def on_stop(self, app): ...
    def on_event(self, event, data): ...
    def get_commands(self): return []

config.json structure

{
  "name": "my_plugin",
  "description": "Does something useful.",
  "enabled_by_default": false
}

Hamster AI will discover and load it automatically on next startup.
