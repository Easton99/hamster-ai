Diagnostics

Built-in tools for understanding what's happening inside Hamster AI.

Opening Diagnostics

Right-click the tray icon → Diagnostics. The diagnostics window shows current-session errors at the top and an expandable section for older history below.

You can also run a quick check in chat with /health.

✅

Health Checks

A set of automated checks that verify Ollama, models, plugins, storage, and more.

📋

Logs

Rotating log files stored locally. View them in-app or open the file directly.

🔧

Self-Fix

Suggested fixes for common problems. Hamster AI always asks before applying anything.

Diagnostics Window

The diagnostics window includes:

  • Current session errors — errors from this run, shown at the top
  • Older errors — expandable section for historical errors
  • Health check results — run on demand or on startup
  • Self-fix suggestions — context-aware fix recommendations
  • Export diagnostic bundle — creates a zip of logs and config for sharing
  • Clear logs — wipes the log file
First step for any issue Open Diagnostics and run a health check. It'll usually tell you exactly what's wrong.
