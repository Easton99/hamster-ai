Mode Settings

Configure what triggers each mode and how they behave.

Note See Functionality → Modes for a full explanation of how each mode works.

Work Mode

SettingDefaultDescription
Protected appsOmnissa Horizon ClientComma-separated list of process names or window title keywords that trigger Work Mode. E.g. horizon, teams, slack
Auto-detect Work ModeOnAutomatically activate Work Mode when a protected app is detected.

Private Mode

SettingDefaultDescription
Auto-trigger keywords(empty)Window title keywords that automatically activate Private Mode. Useful for browsers with private browsing tabs.
Protected apps list(empty)App names that always trigger Private Mode.

Focus Mode

SettingDefaultDescription
Allow plugins during Focus ModeOffIf on, plugins continue running (but notifications are still suppressed).
Allow voice during Focus ModeOffIf on, Voice Output plugin can still speak during Focus Mode.

Game Safe Mode

SettingDefaultDescription
Auto-detect gamesOnAutomatically activate Game Safe Mode when known anti-cheat or game processes are detected.
