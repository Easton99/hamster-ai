Settings

Settings

Open Settings by right-clicking the tray icon and selecting Settings.

Settings are organised into tabs. Changes take effect immediately — no restart required unless noted.

⚙️

General

Model selection, Ollama URL, hotkey, startup behaviour, and chat timestamps.

🎨

Appearance

Theme (Light / Dark / High Contrast) and mini widget position.

🛡️

Mode Settings

Configure protected apps, private mode triggers, and focus mode behaviour.

Settings Storage

All settings are stored in the local SQLite database at data/hamster_ai.db. They persist across restarts and are never synced to the cloud.

Plugins

Plugin enable/disable is managed separately via right-click tray → Plugins, not from the Settings window.

Personality

Personality profiles are stored in config/personality_profiles.json and can be edited from the Settings → Personality tab. Changes take effect on the next message.
