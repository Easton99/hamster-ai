FAQ

Common questions about Hamster AI.

Does Hamster AI require an internet connection?

No. All core features run fully offline. Ollama runs the LLM locally on your hardware. The only optional internet-dependent features (e.g. web search) are disabled by default and don't exist in the current version.

What hardware do I need?

Hamster AI itself is very lightweight. The bottleneck is the Ollama model you choose. A 3B parameter model runs comfortably on 8GB RAM. Larger models (7B, 13B) are faster and smarter on 16GB+ RAM with a discrete GPU.

Will it get me banned from games?

No. Hamster AI is designed specifically to be anti-cheat safe. It does not inject into game processes, hook graphics APIs, read game memory, or automate input. When it detects a game or anti-cheat process, it enters Game Safe Mode and becomes nothing more than a background tray app.

Can I use it with a remote Ollama instance?

Yes. Change the Ollama URL in Settings → General to point to another machine on your network, e.g. http://192.168.1.100:11434.

What Ollama models work?

Any model available through Ollama works. Recommended starting points:

  • llama3.2:3b — fast, low RAM usage, good for most tasks
  • llama3.1:8b — better quality, needs more RAM
  • mistral:7b — good all-rounder
  • phi3:mini — very fast, minimal RAM

Will Hamster AI work with my work VPN or corporate network?

Yes — it only communicates with localhost (Ollama). It doesn't make external network requests. Work Mode ensures it stays completely silent when your corporate environment is detected.

Can Hamster AI see my screen?

No. It reads the active window title and process name (e.g. "VS Code" or "Chrome") but never captures the screen, reads on-screen text, or performs OCR. It will never say "I can see your screen."

How do I change the AI personality?

Go to Settings → Personality. You can edit the default Hamster profile or create new ones. Profiles are stored in config/personality_profiles.json.

Why isn't my plugin loading?

The most common reason is a missing optional dependency. Open Diagnostics → the error message will name the missing package. Install it with pip install <package> and restart the app.

How do I completely remove Hamster AI?

  1. Right-click tray → Exit to close the app
  2. Run the installer and choose Remove, or manually:
    • Delete the project folder
    • Delete data/hamster_ai.db if you want to wipe your data
    • Remove the startup registry entry: HKCU\Software\Microsoft\Windows\CurrentVersion\Run\HamsterAI
    • Delete the Desktop shortcut if you created one

Is Hamster AI free?

Yes. It's open source under GNU GPL v3. Free to use, free to modify, free to redistribute (with attribution, under the same licence).

Where do I report bugs or request features?

Open an issue on GitHub. Or use /add-feature in chat to log it locally to your own feature backlog.
