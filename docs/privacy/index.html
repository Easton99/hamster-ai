Privacy

Hamster AI is built around one principle: your data stays on your machine.

Short version Nothing leaves your PC. No telemetry, no cloud, no accounts. Everything runs locally.

What Hamster AI Never Does

  • Sends data to any external server
  • Takes screenshots or records your screen
  • Logs keystrokes or mouse input
  • Records audio (without the explicit Audio Awareness plugin, which only detects volume levels)
  • Reads game memory or injects into processes
  • Collects telemetry or crash reports
  • Creates accounts or requires sign-in
  • Access Work Mode or Private Mode content

What Is Stored Locally

DataWhereHow to delete
Memories, notes, todosdata/hamster_ai.db/show-memories → delete individually, or delete the database file
Activity logs (session types, durations)data/hamster_ai.db/clear-activity or /forget-today
Settingsdata/hamster_ai.dbReset to defaults from Settings window
App logsdata/logs/hamster_ai.log/clear-logs or delete the file
Personality profilesconfig/personality_profiles.jsonEdit or delete the file

What Is Never Stored

  • Work Mode window titles or activity
  • Private Mode window titles or activity
  • Audio recordings or transcripts
  • Screenshots or screen content
  • Raw chat message content in logs (only metadata)

LLM Inference

All AI inference runs locally via Ollama. Your messages are never sent to OpenAI, Anthropic, or any other external service. The model runs entirely on your hardware.

Deleting Everything

To completely wipe all Hamster AI data:

  1. Delete data/hamster_ai.db — removes all memories, settings, and activity logs
  2. Delete data/logs/ — removes all log files
  3. Delete config/personality_profiles.json — removes custom personality profiles

The app will recreate empty versions of these files on next launch.
