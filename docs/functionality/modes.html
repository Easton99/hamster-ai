Functionality / Modes

Modes

Hamster AI knows when to stay quiet. Modes suppress tracking, notifications, and interruptions automatically.

All modes are core features — they are not plugins and cannot be disabled. They always take priority over personality, plugins, and scheduled tasks.

Work Mode

Work Mode activates automatically when a protected work application is detected — by default, Omnissa Horizon Client (a common corporate virtual desktop client).

What it does

  • Disables greetings, notifications, and all plugin activity
  • Stops observation logging and window title recording
  • Does not call the LLM unless you manually open chat and ask
  • Does not create new memories
  • Shows "Work Mode active — Hamster AI paused" in the tray tooltip

Protected apps

Work Mode triggers when a running process or window title contains: horizon, vmware-view, omnissa, or vmware horizon. You can add more apps in Settings → Mode Settings.

Private Mode

Private Mode can be toggled manually or triggered automatically by sensitive keywords in the active app or window title.

What it does

  • Disables greetings, notifications, audio, and observation logging
  • Does not store window titles or create memories
  • Does not call the LLM automatically
  • Never analyses, summarises, or logs sensitive content
Privacy guarantee Hamster AI only pauses during Private Mode. It will never attempt to categorise or describe what you're doing.

Focus Mode

Focus Mode is triggered manually and runs for a set duration.

Commands

/focus 30Start Focus Mode for 30 minutes
/focus 1hStart Focus Mode for 1 hour
/quietStart Focus Mode with no time limit
/resumeEnd Focus Mode early

What it does

  • Pauses greetings, notifications, and plugin interruptions
  • You can still open chat manually and ask questions
  • Tray icon shows the remaining time

Game Safe Mode

Game Safe Mode activates automatically when anti-cheat or game processes are detected.

Detected processes

VALORANT.exe, RiotClientServices.exe, vgtray.exe, vgc.exe
EasyAntiCheat.exe, EasyAntiCheat_EOS.exe
BEService.exe, BattlEye.exe
FortniteClient-Win64-Shipping.exe, cod.exe, r5apex.exe, cs2.exe

What it does

  • Pauses all plugins and disables overlays and the mini widget
  • Disables voice output and notifications
  • Does not log detailed game window titles
  • The app remains as a normal background tray process only — invisible to anti-cheat
Anti-cheat safety Hamster AI never injects into game processes, hooks graphics APIs, reads game memory, or automates input. It is safe to run alongside any game.

Forget Mode

Forget Mode is not a persistent state — it's a set of commands that let you delete specific data on demand.

/forget-todayClear today's session data and activity logs
/forget-last-hourClear the last hour of activity
/forget-sessionClear the current session
/forget-privateClear any data recorded during the last private session
/clear-activityClear all activity logs
